# Thai interface fonts

- Chonburi Regular: https://github.com/google/fonts/tree/main/ofl/chonburi
- Sarabun Regular and SemiBold: https://github.com/google/fonts/tree/main/ofl/sarabun

Downloaded from the Google Fonts repository. Both font families are distributed
under the SIL Open Font License 1.1; the original license and copyright notices
are included in `Chonburi-OFL.txt` and `Sarabun-OFL.txt`.

The CSS uses the internal family aliases `Village Chonburi` and `Village Sarabun`.
The original font binaries have not been modified.
